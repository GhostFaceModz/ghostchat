Adds the GhostChat assistant widget to your WordPress site.

== Description ==
Install this plugin, paste your GhostChat site key (from the Setup tab of your dashboard), and the widget appears on public pages.

This download is provided from the GhostChat dashboard. It is not listed on WordPress.org unless the owner later asks to submit it.

== Installation ==
1. In WordPress go to Plugins → Add New → Upload Plugin and choose ghostchat-wordpress.zip.
2. Activate GhostChat.
3. Open Settings → GhostChat and paste your site key.
