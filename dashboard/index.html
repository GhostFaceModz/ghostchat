    WordPress and Shopify

    Downloadable installers only. These are not listed on the WordPress or Shopify app stores, and we will not submit them unless you ask.

    Download WordPress plugin
    WordPress install steps
    1. In WordPress go to Plugins → Add New → Upload Plugin and choose the zip.
    2. Activate GhostChat, then open Settings → GhostChat and paste your site key from this page.
    Shopify install steps
    1. Online Store → Themes → Edit code → Snippets → Add a new snippet named ghostchat, and paste the downloaded file.
    2. In layout/theme.liquid, just before </body>, add {% render 'ghostchat' %}.
    3. The downloaded snippet already includes this site's key. If you use the generic file, replace YOUR_SITE_KEY.

    Site search tools
    
          
    Connect a JSON search endpoint or a catalogue feed. When a visitor asks for recommendations or looks for something specific, the bot searches it and shows the results as cards with links to your pages. It only ever shows items your tool returns.
    
          
    
          
    
            
            
            
          
    
          
    URL placeholders: {query} {genre} {mood} {keyword} {year_from} {year_to} {similar_to} {type} {language} {actors} {rating}. Empty ones are dropped from the query string. Fields use dot paths, e.g. poster.url.
